# 予約評価シード

`heldout_seeds.json`は実装時にOS乱数から独立に生成した重複のない64-bit整数1,000個です。学習側はこの集合を除外します。正式評価で使うまで、訓練・重み選択・ハイパーパラメータ調整には使いません。通常の開発評価は別のシードを指定します。

正式評価はcold-clear-2 `ed8b19327b6bd1410ddd873d8611485bd45d8fae`、標準設定・CPU 1ワーカー同士、60 Hz共通ルール・180秒で行います。1,000戦中の勝数だけを成功数とし、引き分けは非勝利です。Wilson 95%下限が0.5を超えることが達成条件です。左右は試合ごとに交代します。

このファイルの存在や短い動作確認ログは、勝利達成の証明にはなりません。
